# rd1.io для Home Assistant

## Установка

1. HACS → ⋮ → Custom repositories.
2. URL: `https://github.com/rd1-io/rd1-homeassistant`  
   Category: **Integration**.
3. HACS → Integrations → **rd1.io** → Download.
4. Перезапустить Home Assistant.
5. Settings → Devices & services → Add integration → **rd1.io**.

В той же сети устройство находится само. Иначе укажите IP контроллера.
